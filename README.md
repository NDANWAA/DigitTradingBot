# Digits Bot - Digital Contracts Specialist

![Digits Bot](https://via.placeholder.com/150)

Advanced bot for trading digit-based contracts on Deriv with dynamic adjustment.

## Features

- **Digit Pattern Detection**: Identifies repeating digit sequences
- **Adaptive Thresholding**: Adjusts requirements based on win/loss streak
- **Aggressive Recovery**: 11x stake multiplier after losses
- **Smart Filtering**: Avoids certain digits (1 and 9)
- **Simulation Mode**: Tests strategies before real trading
